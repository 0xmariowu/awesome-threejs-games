# Monolith Wilds（巨石荒原）原站本地运行文件

## 来源与核对

原站：<https://monolithwilds.vercel.app/>。

2026 年 9 月 26 日，40 个原有运行文件全部与当前原站的 SHA-256 文件校验值一致。离线检查发现字体依赖外网，本轮已补齐原版字体样式表和 8 个字体文件。

本地只替换了字体加载地址，游戏 JavaScript 和游戏 CSS 未改。来源、原始文本和修改记录位于 [provenance/](provenance/)。

## 本地启动

在本目录执行：

```sh
npm start
```

打开 <http://127.0.0.1:8081/>。需要 Node.js，无需安装 npm 依赖。

字体已在断网浏览器中验证，不再请求 Google Fonts。本地服务遇到端口冲突会报错，不会自动跳到其他游戏端口。

## 原游戏操作

- Enter：进入世界。
- WASD：移动。
- 鼠标：查看四周。
- Space、Q：上升和下降。
- Shift：加速。
- F：步行和飞行切换。
- C：电影导览。
- M：地图。
- Esc：设置。

## 实现与验证

游戏使用 Three.js、程序化地形、后台计算线程、图形后处理和合成音频。源码入口见 [TECHNICAL.md](TECHNICAL.md)。

已保存进入世界、移动和性能检查的仓库之外的本地浏览器证据。没有把有限试玩算作所有地标和状态都已验证。全库结论见[检查报告](../catalog/FULL-AUDIT.md)。

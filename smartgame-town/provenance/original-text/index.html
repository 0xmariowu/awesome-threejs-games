    よくある質問

    Q.ブラウザゲームとは何ですか？
    ブラウザゲームは、Chrome や Safari などのウェブブラウザの上でそのまま動くゲームのことです。ウェブゲーム（Webゲーム）とも呼ばれます。アプリのダウンロードやインストールが要らず、URL を開くだけで遊び始められるのが特長です。スマートゲームで公開しているゲームはすべてこのブラウザゲームで、スマホでも PC でも同じ URL で遊べます。
    Q.本当に無料で遊べますか？
    はい。スマートゲームのゲームはすべて無料で遊べます。運営は、ページに表示する広告と、スマゲータウンなどで使える有料アイテム「スマジェム」の販売でまかなっています。スマジェムの購入は任意です。ゲームを最後まで遊んだり、全国ランキングに参加したりするのに購入が必要になることはありません。
    Q.有料アイテム（スマジェム）とは何ですか？
    スマジェムは、スマゲータウンでスマコインへの交換・マイルームの拡張・ペットのおむかえ・デザイン券などに使える有料アイテムです。購入には無料のアカウント登録が必要で、クレジットカードなどで支払えます。購入したスマジェムは、法令で定める場合を除き払い戻しできません。くわしくはスマジェムのページをご覧ください。
    Q.スマホでも遊べますか？
    iPhone・Android のどちらでも遊べます。すべてのゲームがタッチ操作に対応していて、Safari や Chrome などお使いのブラウザでそのまま動きます。PC ではマウスとキーボードで操作でき、画面の大きさに合わせて表示が切り替わります。
    Q.アプリのインストールや会員登録は必要ですか？
    どちらも必要ありません。スマートゲームはインストール不要の無料ブラウザゲームサイトで、会員登録をしなくてもゲストのまま全部のゲームを遊べます。希望する方は Google・LINE・X・Discord またはメールアドレスで無料のアカウントを作れます。アカウントがあると、スマゲータウンのデータを別の端末に引き継いだり、スマジェムを購入したりできます。
    Q.どんなジャンルのゲームがありますか？
    パズル・脳トレ、トランプ、ボードゲーム、アクション、シューティング、スポーツ、カジノ、ローグライト、放置ゲーム、クイズなど幅広いジャンルをそろえています。ページ内のジャンルから探すから気になるジャンルのゲームへ進めるほか、ゲーム一覧のタグで絞り込むこともできます。
    Q.スコアや進み具合は保存されますか？
    ベストスコアや設定は、お使いの端末のブラウザの中に保存されます。次に開いたときも続きから遊べます。全国ランキングに対応したゲームでは、スコアを登録して他のプレイヤーと競えます。お気に入り・ランキング記録・プレイ履歴はマイページでまとめて確認できます。アカウントにログインしていると、スマゲータウンのデータとスマジェムの残高はアカウントに保存され、別の端末でも同じ状態で遊べます。
    Q.対応しているブラウザは何ですか？
    最新版の Google Chrome・Safari・Microsoft Edge・Firefox で動作を確認しています。スマホは iOS の Safari と Android の Chrome を推奨しています。古いブラウザでは一部のゲームが正しく動かないことがあります。
    Q.通信量はどのくらいかかりますか？
    ゲームはすべて軽量に作っていて、読み込みが終わればほとんど通信は発生しません。多くのゲームは最初の読み込みが数百 KB 程度で、3D のゲームでも数 MB 以内です。モバイル回線でも気軽に遊べます。
    Q.不具合や要望はどこに送ればいいですか？
    各ゲームの右上メニューにある「このゲームの不具合報告をする」、またはページ下部のお問い合わせ・不具合報告からお送りください。いただいた内容は順次確認し、ゲームの修正や改善に役立てています。

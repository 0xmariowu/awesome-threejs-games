# Hanakawa（花川）原站本地运行文件

## 来源与核对

原站：<https://hanakawa-boat-game.vercel.app/>。

2026 年 9 月 26 日，重新下载并核对了 214 个运行文件，全部与原站的 SHA-256 文件校验值一致。148 个预加载地址对应的文件也都存在。游戏代码未改。

这是一个 3D 船舶驾驶和河道运输游戏。原始运行文件保留了 Three.js WebGPU 渲染、船舶模拟、地形数据、材质、模型和音频。阅读入口见 [TECHNICAL.md](TECHNICAL.md)。

文件一致不代表所有任务、所有设备都已验证。画面、交互和性能记录见仓库之外的本地检查记录。

## 本地启动

在本目录执行：

```sh
npm start
```

打开 <http://127.0.0.1:8082/>。需要 Node.js，无需安装 npm 依赖。

## 原游戏操作

以游戏内提示为准：

- E：离泊或靠岸。
- W、S：改变油门。
- A、D：转向。
- M：河道地图和任务。
- C：切换跟随、驾驶和摄影视角。

普通 Chrome 中已复现加载停顿：一次等待 80 秒仍在“Lighting the lanterns”，记录到最长 11.925 秒的主线程任务。后续本地运行最终进入了游戏，但不能据此说首次加载问题已修好。

原版加载流程会等待画面刷新，后台标签页可能一直停在加载中。原站在后台等待 75 秒也没有完成加载。打开后应让游戏标签页保持可见，直到出现河道画面。加载长任务与进入游戏后的帧率分开记录，详见仓库之外的本地诊断记录和[全库检查报告](../catalog/FULL-AUDIT.md)。

本地 `server.js` 已改用共享静态服务。端口被占用时会明确报错，不再自动跳到其他游戏的端口。此修改没有触碰原游戏文件。

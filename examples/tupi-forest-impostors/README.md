# Tupi · Forest impostors

Two views expose the archived Tupi forest technique: the original forest
builder, and a controlled grove that compares the original full tree meshes
with the original atlas-backed impostor shader. Source and author:
[Ruben Marcus — Tupi](https://www.rubenmarcus.dev/demos/tupi/).

Run from the repository root:

```sh
node tools/server.mjs examples/tupi-forest-impostors
# http://localhost:8133/
node --test examples/tupi-forest-impostors/*.test.mjs && python3 examples/tupi-forest-impostors/test_browser.py
```

No build step or external requests. Requires WebGPU on localhost or HTTPS.
Shared `ui.js` handles `?lang=zh&theme=dark` and `?lang=en&theme=light`.
Drag to orbit; scroll to zoom.

- **Scene:** the comparison grove or the original forest generated by the unchanged `forest-*.js` default export.
- **Tree rendering (grove):** impostor cards, full meshes, or automatic LOD. Both representations use the same 120 tree placements, heights, rotations and three scanned variants. Automatic mode uses full meshes within 180 units of a row's center and cards farther away.
- **Draw distance:** adjusts the camera far plane (80–1600). Grove rows are also culled by center distance.
- **Pause:** freezes the original foliage animation while leaving the camera and controls available.
- **Performance:** live renderer triangle and draw counts for the current view, including the host ground and renderer passes.

The grove uses unchanged exports from `species-*.js`: scan loading (`a`),
impostor sizing (`n`), card generation (`r`), mesh instancing (`p`), bark and leaf
materials (`S`, `T`), and foliage updates (`E`). The host owns placement,
visibility and the 180-unit threshold. The unchanged `environment-*.js` supplies
the original sun, generated sky environment and height-dependent mist. The host
starts at the forest chapter (104 seconds) and adds neutral diffuse fill at
intensity 8 so the dark Lambert atlases remain legible without the film
pipeline's scene-dependent automatic exposure. The comparison uses neutral
material tint parameters to make both representations legible.

The original forest view retains the archive's low-quality layout and its
fixed distance bands relative to the cinematic path. **It has no native runtime
full-mesh toggle.** The representation selector is therefore disabled in that
view; the switch and camera-distance LOD belong to the explicitly labelled
comparison grove. No replacement shader or fabricated tree asset is used.

Limitations: `nospecies` skips the optional later species-model upgrade, while
retaining original scanned trees, flora atlases, procedural special species and
understory props. The forest uses its own built-in height fallback because the
full terrain module is not loaded. A flat ground plane replaces the full terrain. The original environment and
weather run unchanged; the film's terrain, water, audio and post-processing are
outside this example. Diffuse fill is calibrated for this standalone fixture;
this is not pixel-identical full-film lighting. Card alpha dithering is part of the original shader.
The archive is credited as received; no additional license grant is asserted.

All required chunks and flora assets are byte-identical under `original/`.
`provenance.json` pins every archive path, source URL and SHA-256. The import
closure excludes `main-*.js`; `src/host.js` only relocates asset URLs.
Browser tests use installed headless Chrome sequentially and verify language,
theme, real controls, pixel changes, mesh/card triangle and draw-count changes,
automatic LOD, draw distance, the original forest view, fixed canopy-crop
luminance floors in both views, and zero console/HTTP errors. The required screenshot is saved to the task's scratchpad `shots/` directory.

# Original prompt

[`original.txt`](original.txt) contains the original English sky-theme prompt,
verbatim, recovered from the project's conversation on September 15, 2026.
It introduced Cloudkeep as a 3D airship and sky-creature feeding game.

The finished project was developed iteratively. Later feedback added capture
and coin rewards, more creature species, revised flight controls, softer stone,
layered clouds, stronger lighting, particles and a beatless soundscape.
The original prompt is preserved without rewriting it to describe those later changes.

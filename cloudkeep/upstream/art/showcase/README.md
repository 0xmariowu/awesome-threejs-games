# Cloudkeep showcase

This documents the earlier 30 fps export. The current release is the
[4K60 gameplay retake](README-4K60.md). Video binaries are distributed through
GitHub releases and are not included in the Git checkout.

Recorded on 2026-09-15 from the running game at native 3840 x 2160 resolution.
The sequence uses the existing game models, simulation, AI, particles and audio,
with directed cameras, edited shots and brief presentation captions.

## Deliverables

- `Cloudkeep-4K-Showcase.mp4`: 3840 x 2160, 30 fps, 41.1 seconds, H.264 High / AAC stereo.
- `Cloudkeep-1080p-Share.mp4`: 1920 x 1080 sharing copy of the same sequence.
- `Cloudkeep-Cover.jpg`: 4K frame extracted from the finished video.

## Sequence

- 0–4 seconds: airship and floating gardens.
- 4–12 seconds: free flight, climbing and mechanical boost trails.
- 12–19 seconds: ray capture, disappearance, collectible coins and bait release.
- 19–32 seconds: animated whale, moth, jelly and koi closeups.
- 32–41 seconds: lighthouse, gardens and layered cloud panorama.

Audio retains the game's beatless atmosphere, engine, creature and reward sounds.
The final mix measures -18.2 LUFS integrated with a -3.3 dBFS true peak.
Both MP4 files use fast-start metadata and pass full FFmpeg decoding without errors.
Both contain 1,233 video frames and a stereo 48 kHz audio track. Opening, action,
capture, creature and closing frames were visually checked.

An isolated demo browser save was used. The player's existing save was preserved,
and the game source was not changed for the recording.

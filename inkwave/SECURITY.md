# Security

Security fixes are handled on the default branch. Older snapshots do not have
a separate maintenance commitment.

Please report vulnerabilities privately using
[GitHub private vulnerability reporting](https://github.com/0xmariowu/inkwave/security/advisories/new).
Include affected files, reproduction steps, impact, and a suggested fix if known.
Do not include real credentials or publish an exploit in a public issue.

The game has no account backend; profile and settings data live in the browser's
local storage. The bundled Python HTTP server is for local development only.

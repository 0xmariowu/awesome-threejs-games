# Arkenfall implementation guide

Follow these modules' imports into worker files for terrain, geometry, texture atlases, lighting, map painting and synthesized audio. The original game schedules work across Web Workers and caches generated data in IndexedDB. Preserve those worker URLs and origin boundaries when experimenting.

The HTML loading screen selects ten paintings by assembling `loading/art-<id>.webp` from an array. IDs are 02 through 11. All ten were captured explicitly; a literal URL scan alone found only the initially selected painting. Fraunces and Manrope fonts, app icons, the web manifest and share image are also included.

## Runtime and saves

The original game exposes `window.__game`; `window.__ready` becomes true after initial rendered frames. `__game.started` and `__game.player.control` distinguish playable gameplay from a rendered title screen. `__game.failed` records failed subsystem loading. The audit checks these states alongside screenshots and actual movement.

`__game.gameplay.snapshot()` returns the original progress structure. The storage key is `arkenfall.save.v1`. Quest progression, rest/checkpoint actions and page lifecycle events invoke the original save code. Continue restores a checkpoint; it does not promise the exact position where the tab was closed. UI preferences and map discoveries have separate storage. IndexedDB caches generated resources rather than acting as a remote game service.

The captured entry already disables Vercel analytics on `localhost`, `127.0.0.1` and `::1`. Analytics files remain archived with original bytes. No synthetic API or server response was added.

## Reproduce the checks

From the collection root, with port 8099 running:

```sh
python3 tools/audit.py arkenfall
```

The browser scripts require Python Playwright and installed Chrome. They use isolated browser storage and run sequentially. Local tests block external traffic. The default game quality and adaptive-resolution behavior stay unchanged. Frame callback timing measures stalls and pacing; it is not proof of GPU throughput or of smooth performance everywhere in the world.

`public/` is the immutable reference runtime. Keep experiments elsewhere. Deployed minified modules retain useful subsystem boundaries, but original authoring source, source maps and an upstream development repository have not been recovered.
